# Job Market Analyzer — Session Summary / 学习简报

归档日期：2026-10-11（America/Edmonton）。本日志覆盖 2026-10-08 至 2026-10-11 的连续开发工作；字段和值只记录已验证结果。

- **职位数据管道已接通。** Greenhouse 官方 board 数据经过来源字段保留、Pydantic `JobExtraction` 校验、GeoNames 地点解析和 MySQL 写入。职位与 `job_skills`、`job_locations` 分别通过关联表保存。
  **The job-data pipeline is connected.** Official Greenhouse board data retains source fields, passes Pydantic `JobExtraction` validation, resolves locations through GeoNames, and is written to MySQL with `job_skills` and `job_locations` junction tables.
- **地点选择已从地图接入后端。** 前端提交坐标到 `/api/location`，后端返回国家、省份和附近地点选项。用户选择的地点保存其 GeoNames ID、地点类型和国家 ID，用于推荐筛选。
  **Map location selection reaches the backend.** The front end sends coordinates to `/api/location`; the backend returns country, province, and nearby choices. The selected place retains its GeoNames ID, type, and country ID for recommendation filtering.
- **数据提取采用严格证据规则。** 薪资、语言、学历、工时和地点只在原职位文本或 Greenhouse offices 明确支持时写入；缺失或无法唯一解析时保持 `NULL` / 未关联，不估算或补猜。
  **Extraction uses strict source evidence.** Salary, language, education, work schedule, and location are written only when the posting text or Greenhouse offices explicitly supports them. Missing or ambiguous values remain `NULL` / unlinked.
- **技能关联走标准词典。** 只有能映射到 `skills` / `skill_aliases` 的规范技能会写入 `job_skills`；不能匹配的候选不会作为虚构技能保存。
  **Skill links use the canonical dictionary.** Only terms that map through `skills` / `skill_aliases` are stored in `job_skills`; unmatched candidates are not saved as invented skills.
- **已导入多家公司。** 当前数据库有 2,374 个职位、17,013 条技能关联、3,248 条地点关联和 120 个地点记录。主要 Greenhouse 来源包括 Stripe、Cloudflare、Datadog、MongoDB、Okta、Coinbase、Figma、Twilio 与 Duolingo。
  **Multiple companies are imported.** The current database contains 2,374 jobs, 17,013 skill links, 3,248 location links, and 120 location records. Main Greenhouse sources include Stripe, Cloudflare, Datadog, MongoDB, Okta, Coinbase, Figma, Twilio, and Duolingo.
- **MongoDB 第一轮完成。** 官方 board 当前有 392 个职位；按北美、英国、欧洲、澳新优先范围处理了 249 条。249/249 通过 BaseModel 校验并入库；其中 136 条有来源明确支持的工资，218 条建立了地点关联，239 条建立了技能关联。
  **MongoDB first pass completed.** The official board currently has 392 jobs; 249 target-region postings were processed. All 249 passed BaseModel validation and were saved; 136 have source-supported salary, 218 have location links, and 239 have skill links.
